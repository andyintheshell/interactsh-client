# Upstream provenance

`interactsh-client` is an independent maintenance fork created by
[andyintheshell](https://github.com/andyintheshell) from the published
[`interactsh` 0.2.4](https://crates.io/crates/interactsh/0.2.4) crate, originally
authored by Santh. The original crate was no longer maintained, and its listed
source repository was unavailable (404) when this fork was created on 2026-11-06.
This project is not affiliated with or endorsed by the original maintainers.

The `interactsh-client` fork has not been published to crates.io. Its first
planned release is **0.1.0**, with versioning independent of the original
`interactsh` crate. The published version and date below refer only to upstream.

## Source

- Original crate: `interactsh`
- Original version: `0.2.4`
- Published: 2026-08-08 (UTC)
- Listed repository: <https://github.com/santhreal/interactsh>
- Source archive: <https://crates.io/api/v1/crates/interactsh/0.2.4/download>
- Archive SHA-256: `e884740e67056f10bf347f042a3ee83cd4d4927a9bfc713303e74be4e627a18e`

The initial commit imports the published archive unchanged. The archive's
`.cargo_vcs_info.json` reports upstream revision
`acfec64e0ef6ca4a8c3ce1361eee114808254235` with `dirty: true`, so the verified
archive, not that revision, is the authoritative source for this fork. The
registry-generated manifest and VCS metadata were then removed or replaced for
the standalone repository; dependency versions and library behavior were retained.
